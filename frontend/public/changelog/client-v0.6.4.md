### Windows 程序自动填充

- 不再因出现密码框就自动弹窗；改为先点击密码框，再按全局快捷键触发（默认 Ctrl+Alt+K）
- 快捷键可在「设置 → 程序自动填充快捷键」中修改并持久保存
- 未识别到密码框或保险库已锁定时给出明确提示

### GitHub 自动更新

- 启动时静默检查最新 Release；有新版本时设置导航显示红点
- 设置页可手动检查、后台下载安装包到安装目录 `cache\`，校验通过后再安装
- 点击「开始安装」后退出主程序并启动安装向导；安装成功后清理缓存安装包
- 便携解压版不走自动安装，可从设置打开 GitHub 发布页

### 其它

- 新建条目时密码等敏感字段默认隐藏
- 打包产物新增安装包校验文件，自动更新依赖此文件
